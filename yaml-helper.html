YAML-Block

Ans Ende von fundus.yaml anfügen (gleiche Einrückung wie die anderen Items, jeweils mit - id: beginnend). Reihenfolge in der Datei ist egal, nur die id muss einzigartig sein.

Lokal siehst du den neuen Eintrag in index.html erst nach einem Build: im Ordner build/ einmal npm install, danach npm run build:all (siehe README). Ohne lokalen Build erledigt das die GitHub Action automatisch nach dem Push.
